# mini-react (version1)

Учебный мини‑движок в стиле React, демонстрирующий базовые идеи Virtual DOM и хуков.

## Видео 

[![Видео здесь](https://img.youtube.com/vi/q9OKsyiOUKU/0.jpg)](https://www.youtube.com/watch?v=q9OKsyiOUKU)

## Основные идеи
- Virtual DOM (`createElement`)
- Рекурсивный render + diff
- Функциональные компоненты
- Простейшие хуки (`useState`, `useMemo`)

## Ключевое ограничение
Состояние хранится на уровне **функции компонента**, а не экземпляра.
Это означает, что несколько одинаковых компонентов разделяют один и тот же state.

Эта версия намеренно наивная и используется как отправная точка для объяснения,
почему React пошёл дальше и зачем понадобился Fiber.

## Назначение репозитория
Учебный.
Подходит для:
- понимания Virtual DOM
- демонстрации проблемы хранения состояния
- сравнения с более продвинутой архитектурой version2
