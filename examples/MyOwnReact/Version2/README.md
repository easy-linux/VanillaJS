# mini-react (version2)

Улучшенная версия mini-react с Fiber‑архитектурой и оптимизациями рендера.

## Видео 

[![Видео здесь](https://img.youtube.com/vi/CkvQCm_ibos/0.jpg)](https://www.youtube.com/watch?v=CkvQCm_ibos)

## Что изменилось по сравнению с version1
- Введена структура Fiber — состояние хранится **по экземпляру компонента**
- Реализован reconciliation Fiber‑узлов
- Добавлена оптимизация bailout (пропуск рендера)
- Введены флаги dirty / childDirty
- Улучшен JSX‑like html парсер

## Ключевые идеи
- Fiber как паспорт экземпляра компонента
- Сохранение состояния между рендерами
- Минимизация повторных вычислений
- Архитектура, близкая к реальному React

## Назначение репозитория
Учебный, продвинутый.

Подходит для:
- глубокого понимания внутренней архитектуры React
- объяснения reconciliation и Fiber
- демонстрации, что React — это инженерия, а не магия
